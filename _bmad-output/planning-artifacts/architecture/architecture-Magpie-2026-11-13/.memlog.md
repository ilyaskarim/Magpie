- (direction) Fast path, build-substrate only, no extra renderings: owner brief asks for one proportionate planning pass and to decide non-blocking calls without asking.
- (constraint) Inputs: spec-magpie-mvp SPEC.md + stack.md + build-stages.md + product-intent.md; stage (a) code in src-tauri (tray.rs, hotkey.rs, window.rs, error.rs). Stack fixed.
- (decision) AD-1 paradigm hexagonal (ports and adapters) inside src-tauri: domain (pure) <- ports (traits) <- adapters (OS, SQLite) <- shell (Tauri commands, tray, window). Prevents OS/Tauri leaking into testable logic; brief requires clipboard + storage behind traits.
- (decision) AD-2 Rust is the only writer of history and settings; frontend reads via commands and mutates only by calling commands; backend emits history-changed after every mutation and UI refetches. Prevents divergent UI-side state.
- (decision) AD-3 item identity: UUIDv4 string id assigned at first capture, never changed; dedupe key = SHA-256 of kind + canonical payload; dedupe hit updates last_copied_at (and source app) on existing row, keeps id and pin. Prevents sync-breaking id churn and two dedupe definitions.
- (decision) AD-4 time: i64 unix milliseconds UTC in DB and DTOs; UI formats locally. Ordering by last_copied_at desc.
- (decision) AD-5 images: PNG at app_data/images/{id}.png, DB stores relative path; Store owns both row and file; delete removes file after row; startup sweep deletes orphan files. Prevents blob storage and leaked files.
- (decision) AD-6 privacy filter is a pure domain fn evaluated on (available formats, source app, paused, ignore list) BEFORE reading content; concealed/transient markers never trigger a content read.
- (decision) AD-7 Magpie's own clipboard writes (paste-back) are marked by the capture loop (expected-change token) and not treated as new external copies: they only bump the existing item, source app unchanged.
- (decision) AD-8 search: FTS5 table over text items (unicode61, remove_diacritics) kept in sync by triggers; query = each user token as prefix term ANDed; empty query = plain recency list. Search runs in Rust only.
- (decision) AD-9 command/DTO contract: Tauri commands snake_case verbs; DTOs serde rename_all camelCase; errors via AppError serialized to a readable string; src/api.ts is the only frontend module that calls invoke/listen.
- (decision) AD-10 settings: one typed Settings struct persisted as JSON in a settings table row; update_settings validates and applies side effects (hotkey re-register, autostart) atomically; invalid -> readable error, previous value kept.
- (decision) AD-11 concurrency: capture watcher on its own thread; Store behind Arc<Mutex<...>> in Tauri managed state; no async runtime in domain; DB work never on the UI thread for >1 op at a time is acceptable at MVP scale.
- (decision) AD-12 paste-back: frontmost app captured when the hotkey shows the window (before focus moves); paste = write clipboard, hide window, reactivate saved app, short settle delay, synthetic Cmd/Ctrl+V; no permission -> copy only + UI notice.
- (version) Versions verified 2026-11-13: tauri 2.12.5, global-shortcut 2.4.1, single-instance 2.5.5, rusqlite 0.42.0 (bundled has FTS5), clipboard-rs 0.3.5, React 19, Vite 8, TS 6.
- (assumption) Paste settle delay ~50-100 ms tuned during stage c.
- (question) Deferred: Linux adapters, sync protocol, encryption at rest, migrations framework beyond user_version pragma.
- (event) Reviewer gate: lint 0 findings; currency review (strong, 1 high C-1); adversarial review (4 high, 5 medium). All clear fixes applied below.
- (decision) AD-7 tightened: paste service bumps the item itself, then records the OS clipboard sequence number after its write (macOS changeCount, Windows GetClipboardSequenceNumber); capture loop drops changes with seq <= recorded. No content matching, no skip-next flag.
- (decision) AD-3 tightened: source_app updates only on external re-copies (never on Magpie's own writes, per AD-7).
- (decision) AD-13 new: kind precedence files > image > html > text; all available representations stored (plain text always when present); paste writes every stored representation back.
- (decision) AD-14 new: CoreError (thiserror, no Tauri types) in domain/ports/adapters; shell AppError wraps it via From and serializes to a readable string. Stage-a AppError moves to shell.
- (decision) AD-10 tightened: SettingsService (Arc<RwLock<Settings>>) is the single in-memory owner incl. paused and ignored_apps; tray, commands, hotkey change it only via SettingsService::update, which writes through to the store and emits settings-changed; capture loop reads a snapshot per change. paused persists across restarts (privacy: never resume capture silently). Hotkey change registers new before unregistering old; on failure old stays.
- (decision) AD-15 new: retention ages by last_copied_at; runs at startup, after each insert, after limit changes, hourly; one transaction; emits history-changed.
- (decision) AD-16 new: storage root app_local_data_dir (not roaming); DB <root>/magpie.db; images <root>/images/; items table seq INTEGER PRIMARY KEY + id TEXT UNIQUE; FTS content_rowid=seq; never INSERT OR REPLACE. List DTO carries <=200-char preview and imageUrl via asset protocol scoped to <root>/images/**.
- (decision) AD-17 new: UI contract: selection kept by item id; backend emits window-shown when hotkey shows window, UI resets query/selection then. Events: history-changed, settings-changed, window-shown.
- (decision) AD-18 new: startup order open DB -> migrate -> orphan sweep -> retention -> load settings -> register hotkey from settings -> start watcher. Clipboard content present at launch is not captured. Watcher thread supervised (catch_unwind + restart with backoff).
- (decision) AD-12 tightened: macOS 14+ cooperative activation (yieldActivationToApplication then activate), then wait until frontmost pid == saved pid (timeout ~300 ms) before posting Cmd+V; Windows SetForegroundWindow on saved HWND then SendInput.
- (decision) AD-6 wording: marker-format values (e.g. CanIncludeInClipboardHistory DWORD) may be read; content payloads may not, before the filter passes.
- (version) Native bindings: objc2-app-kit 0.3, objc2-core-graphics 0.3, objc2-application-services 0.3 (already Tauri's family); windows 0.62; tauri-plugin-autostart 2.7 with MacosLauncher::LaunchAgent; TypeScript 6.0 kept (7.x deferred until toolchain compat checked); rusqlite pinned 0.42.0.
