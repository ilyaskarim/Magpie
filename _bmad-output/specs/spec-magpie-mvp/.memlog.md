- (direction) Input: _bmad-output/planning-artifacts/product-intent.md (owner brief). Brief wins over any BMad output; stack, MVP scope, out-of-scope and build order a-g are fixed, not reopened.
- (decision) Mode: express. Input is rich and pre-sorted; no elicitation.
- (capability) CAP-1 capture: background listener records every clipboard change (plain text, HTML/rich text, images, file paths) with timestamp and source app where the OS exposes it.
- (capability) CAP-2 dedupe: re-copying content already in history moves that item to the top, no second entry.
- (capability) CAP-3 history window: global hotkey (default CmdOrCtrl+Shift+V, user-configurable) opens newest-first list with type-appropriate previews; arrows move, Enter pastes, Esc dismisses, typing searches.
- (capability) CAP-4 search: full-text over text items, results as you type, <50 ms at 10,000 items.
- (capability) CAP-5 paste-back: selecting an item writes it to the clipboard, hides the window, refocuses the previous app and pastes there; macOS Accessibility first-run flow; fallback 'copied, press paste yourself' when refused.
- (capability) CAP-6 pins: user pins items; pinned survive cleanup; pinned items viewable separately.
- (capability) CAP-7 privacy: skip concealed items (org.nspasteboard.ConcealedType / ExcludeClipboardContentFromMonitorProcessing), user-editable ignored-apps list, pause-capture toggle.
- (capability) CAP-8 retention: configurable max age and max count, pinned exempt; images stored as files on disk and deleted with their rows.
- (capability) CAP-9 tray: tray/menu bar icon with open, pause, settings, quit; optional launch at login.
- (capability) CAP-10 settings screen: edit hotkey, ignored apps, retention limits, launch at login, pause. Own capability because CAP-3/7/8/9 all need user configuration (brief stage f names a settings screen).
- (constraint) Stack fixed: Tauri 2 + Rust backend, React+TS+Vite frontend, SQLite via rusqlite with FTS5. All capture/storage/search logic in Rust; frontend is thin view calling Tauri commands.
- (constraint) Local-only: no network calls, no telemetry, no account.
- (constraint) Future-proofing: storage behind a trait; every item has a stable UUID (sync not built but not blocked).
- (constraint) Idle CPU near zero; prefer OS change notifications; poll only where no notification exists, sane interval, documented.
- (constraint) Hotkey window appears <150 ms; window kept alive and hidden, never recreated.
- (constraint) Rust: no unwrap() on OS/disk paths; errors surface to UI as readable messages.
- (constraint) Testability: OS clipboard behind a trait; unit tests for dedupe, retention, search, privacy filters run against a fake clipboard.
- (constraint) Name 'Magpie' in one config place; do not copy Paste's name, visual design, icons or copy.
- (constraint) Platforms: macOS and Windows for MVP, Linux later. Develop on macOS, verify on Windows; untested OS paths listed as untested.
- (constraint) Process: stop and ask before adding unmaintained or copyleft deps, changing stack, or cutting MVP scope.
- (decision) Monitoring (pre-planning, recorded in DECISIONS.md): own watcher on clipboard-rs 0.3.5 (MIT); macOS polls NSPasteboard.changeCount at 500 ms (no OS notification exists); Windows uses WM_CLIPBOARDUPDATE.
- (note) Non-goals: cross-device sync, mobile apps, accounts, team sharing, AI features, payments, auto-update, Linux support in MVP.
- (decision) Build order fixed as stages a-g; checkpoint with owner after a(+BMad) and after c. Stage a done before planning.
- (assumption) Settings persist locally in the app data dir; no cloud.
- (assumption) Rich text captured as HTML plus its plain-text form; RTF-only copies keep the plain-text form. Previews show sanitised HTML or plain text.
- (assumption) Default retention when unset: 90 days and 5,000 items, both editable (brief gives no defaults).
